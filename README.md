# Guidance Management System

A desktop-based Guidance Management System developed using Java Swing and MySQL.

## Features

- User Login
- User Registration
- Student Profiling
- Counseling Management
- Concern Management
- Case Management
- CRUD Operations
- MySQL Database
- Printable Reports

## Technologies Used

- Java
- Java Swing
- Apache NetBeans
- MySQL
- XAMPP
- JDK 23
- Launch4j
- Inno Setup Compiler
